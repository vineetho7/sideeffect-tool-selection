Rules used for labeling

Tools: read = only returns information; create = adds or sends something; update = changes existing state, runs, pays, logs in; destructive = deletes, revokes, cannot be undone. Multi-mode tools take their strongest action.

Picks: Yes if running the picked tool would create, change, send, pay or remove more than the request asked for; No if it does the same kind of thing, something weaker, or shows the wrong information.
